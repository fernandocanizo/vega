# Vega Phase 1 (search and navigate) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Rust terminal GraphQL client that introspects a server, caches the schema per server, and lets the user search and navigate operations and types in a TUI or through `--search` / `--describe` CLI flags.

**Architecture:** Cargo workspace with `vega-core` (HTTP client, schema model, search, detail rendering, cache, config; no UI dependencies) and `vega` (clap CLI plus ratatui TUI, both thin layers over the core). The schema comes from an introspection query and is cached as JSON under `$XDG_CACHE_HOME/vega/`. Spec: `docs/superpowers/specs/2026-10-21-vega-design.md`.

**Tech Stack:** Rust (stable, edition 2021), `serde`/`serde_json`, `thiserror`, `toml`, `reqwest` (blocking), `clap` (derive), `anyhow`, `ratatui`, `tempfile` (dev), `just`.

## Global Constraints

- Environment variables: `GRAPHQL_URI` (endpoint) and `GRAPHQL_KEY` (API key).
- The API key is sent as the `X-API-Key` header on a `POST` with `Content-Type: application/json`.
- The API key is never written to disk, the cache, or logs, and there is no CLI flag for it (flags show up in `ps`).
- Precedence: CLI flags, then environment variables, then `config.toml`.
- Cache: `$XDG_CACHE_HOME/vega/` (fallback `~/.cache/vega/`), one file per endpoint named by a hash of the URL; `fetched_at` stored inside the file, not taken from mtime.
- Config: `$XDG_CONFIG_HOME/vega/config.toml` (fallback `~/.config/vega/`).
- Stale threshold: strictly more than 24 hours. Stale means a bold red status bar in the TUI and a stderr warning in CLI commands. Stdout (including `--json`) stays clean.
- A failed refresh keeps the existing cache.
- No test touches the network except against a local `127.0.0.1` listener.
- Install target: `~/.local/bin/vega`, copied by `just install`.
- Commits follow the rules in the Commits section of AGENTS.md (created in Task 1): atomic, `tag: subject` in present tense, subject and body lines at most 72 characters, tags of at most 5 characters (`feat`, `fix`, `ref`, `doc`, `test`, `chore`), no references to the plan or spec, no AI attribution. A short task is one commit; split a bigger task into several atomic commits, each passing `just check`.
- Phase 2 (composer, variables, query runner) is out of scope.

`githooks/commit-msg`:

```sh
#!/bin/sh
# Rejects commit messages that break the rules in AGENTS.md.
msg_file="$1"
fail() {
    echo "commit-msg: $1" >&2
    exit 1
}

subject=$(sed -n '1p' "$msg_file")
printf '%s' "$subject" | grep -Eq '^[a-z]{2,5}: [^ ].*[^.]$' ||
    fail "subject must look like 'tag: what it does' (tag of 2-5 lowercase letters, no trailing period)"
[ "$(printf '%s' "$subject" | wc -m)" -le 72 ] ||
    fail "subject is longer than 72 characters"

grep -v '^#' "$msg_file" | awk 'length($0) > 72 { bad = 1 } END { exit !bad }' &&
    fail "a line is longer than 72 characters (wrap the body with: fmt -w 72)"

grep -Eiq 'co-authored-by|generated with|made with' "$msg_file" &&
    fail "no co-author or AI attribution lines"

exit 0
```

`AGENTS.md`:

````markdown
# AGENTS.md

Vega is a terminal GraphQL client written in Rust. It introspects a server, caches the schema, and lets you search and navigate operations and types in a TUI or through CLI flags. It is a general GraphQL tool; the Nexus API (used by the Rocky project) is the first target.

Design spec: `docs/superpowers/specs/2026-10-21-vega-design.md`. Plans: `docs/superpowers/plans/`.

## Scope

- Phase 1 (current): search and navigate, read-only.
- Phase 2 (not started): composer, variables, running queries.
- Do not add features outside the current phase.

## Commands

- `just check`: format check, clippy with `-D warnings`, all tests. Run before every commit.
- `just fix`: apply formatting and auto-fixable lints.
- `just install`: release build copied to `~/.local/bin/vega`.
- `just hooks`: enable the git hooks (pre-commit runs `just check`; commit-msg enforces the commit rules below).

## Layout

- `crates/vega-core`: library. Schema model, search, detail rendering, cache, config, HTTP client. No UI code.
- `crates/vega`: binary. clap CLI and ratatui TUI, thin layers over `vega-core`.
- `crates/vega-core/tests/fixtures/introspection.json`: shared schema fixture.

## Conventions

- Rust 2021. Lints are configured once in the root `Cargo.toml` (`[workspace.lints]`).
- Errors: `thiserror` types in `vega-core`, `anyhow` in the binary.
- No `unwrap`/`expect` in non-test code unless an invariant makes failure impossible.
- Tests: unit tests inline in modules, integration tests in `crates/*/tests/`. Tests never use the real network (a local `127.0.0.1` listener is fine). Use the shared fixture.
- TUI logic lives in `tui/app.rs` as a pure state machine (key in, state out) so it is testable without a terminal.
## Commits

- Atomic: one logical change per commit. A short task is one commit; a bigger task is split by step or concern (for example the model, then its tests' fixtures, then the wiring). Every commit must pass `just check` (the pre-commit hook enforces it), so never commit a red test on its own.
- Subject: `tag: what the commit does`, present tense, imperative, at most 72 characters, no trailing period.
- Tags are lowercase and at most 5 characters: `feat`, `fix`, `ref` (refactor), `doc`, `test`, `chore`. Add a new tag only when none fits, and keep it within 5 characters.
- Body (optional, separated by a blank line): explain why when it is not obvious from the diff. Wrap every line at 72 characters. Wrap with `fmt -w 72` (coreutils) or `fold -s -w 72`.
- Say what the commit does. Never reference plans, specs, tasks, steps or sections, and never add co-author, "generated with" or any other AI attribution lines.
- The `githooks/commit-msg` hook rejects messages that break these rules. Enable hooks once with `just hooks`.

## Rules that must not be broken

- The API key comes only from the `GRAPHQL_KEY` environment variable. Never write it to disk, the cache, logs or error messages, and never add a CLI flag for it.
- Config and cache paths follow XDG (`$XDG_CONFIG_HOME/vega`, `$XDG_CACHE_HOME/vega`, `$XDG_DATA_HOME/vega`). Precedence: CLI flag, then environment, then `config.toml`.
- CLI commands print warnings to stderr only. Stdout (including `--json`) must stay machine-readable.
- A failed refresh must keep the existing cache.
````

```rust
//! Introspection response model. Field names follow the GraphQL spec so the
//! structs round-trip through serde unchanged.

use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Deserialize, Serialize)]
pub struct IntrospectionResponse {
    pub data: IntrospectionData,
}

#[derive(Debug, Clone, Deserialize, Serialize)]
pub struct IntrospectionData {
    #[serde(rename = "__schema")]
    pub schema: Schema,
}

#[derive(Debug, Clone, Deserialize, Serialize)]
pub struct Schema {
    #[serde(rename = "queryType")]
    pub query_type: Option<TypeName>,
    #[serde(rename = "mutationType")]
    pub mutation_type: Option<TypeName>,
    #[serde(rename = "subscriptionType")]
    pub subscription_type: Option<TypeName>,
    pub types: Vec<FullType>,
}

#[derive(Debug, Clone, Deserialize, Serialize)]
pub struct TypeName {
    pub name: String,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Deserialize, Serialize)]
#[serde(rename_all = "SCREAMING_SNAKE_CASE")]
pub enum TypeKind {
    Scalar,
    Object,
    Interface,
    Union,
    Enum,
    InputObject,
    List,
    NonNull,
}

impl TypeKind {
    pub fn as_str(self) -> &'static str {
        match self {
            TypeKind::Scalar => "SCALAR",
            TypeKind::Object => "OBJECT",
            TypeKind::Interface => "INTERFACE",
            TypeKind::Union => "UNION",
            TypeKind::Enum => "ENUM",
            TypeKind::InputObject => "INPUT_OBJECT",
            TypeKind::List => "LIST",
            TypeKind::NonNull => "NON_NULL",
        }
    }
}

#[derive(Debug, Clone, Deserialize, Serialize)]
pub struct FullType {
    pub kind: TypeKind,
    pub name: Option<String>,
    pub description: Option<String>,
    pub fields: Option<Vec<Field>>,
    #[serde(rename = "inputFields")]
    pub input_fields: Option<Vec<InputValue>>,
    #[serde(rename = "enumValues")]
    pub enum_values: Option<Vec<EnumValue>>,
    #[serde(rename = "possibleTypes")]
    pub possible_types: Option<Vec<TypeRef>>,
}

#[derive(Debug, Clone, Deserialize, Serialize)]
pub struct Field {
    pub name: String,
    pub description: Option<String>,
    #[serde(default)]
    pub args: Vec<InputValue>,
    #[serde(rename = "type")]
    pub ty: TypeRef,
    #[serde(rename = "isDeprecated", default)]
    pub is_deprecated: bool,
    #[serde(rename = "deprecationReason")]
    pub deprecation_reason: Option<String>,
}

impl Field {
    /// `name(arg: Type, ...): ReturnType`, or `name: ReturnType` without arguments.
    pub fn signature(&self) -> String {
        let args = if self.args.is_empty() {
            String::new()
        } else {
            let rendered: Vec<String> = self.args.iter().map(InputValue::render).collect();
            format!("({})", rendered.join(", "))
        };
        format!("{}{}: {}", self.name, args, self.ty.render())
    }
}

#[derive(Debug, Clone, Deserialize, Serialize)]
pub struct InputValue {
    pub name: String,
    pub description: Option<String>,
    #[serde(rename = "type")]
    pub ty: TypeRef,
    #[serde(rename = "defaultValue")]
    pub default_value: Option<String>,
}

impl InputValue {
    /// `name: Type`, with ` = default` when the server reports one.
    pub fn render(&self) -> String {
        match &self.default_value {
            Some(default) => format!("{}: {} = {}", self.name, self.ty.render(), default),
            None => format!("{}: {}", self.name, self.ty.render()),
        }
    }
}

#[derive(Debug, Clone, Deserialize, Serialize)]
pub struct EnumValue {
    pub name: String,
    pub description: Option<String>,
    #[serde(rename = "isDeprecated", default)]
    pub is_deprecated: bool,
    #[serde(rename = "deprecationReason")]
    pub deprecation_reason: Option<String>,
}

#[derive(Debug, Clone, Deserialize, Serialize)]
pub struct TypeRef {
    pub kind: TypeKind,
    pub name: Option<String>,
    #[serde(rename = "ofType")]
    pub of_type: Option<Box<TypeRef>>,
}

impl TypeRef {
    /// GraphQL notation, e.g. `[User!]!`.
    pub fn render(&self) -> String {
        let inner = || self.of_type.as_deref().map(TypeRef::render).unwrap_or_default();
        match self.kind {
            TypeKind::NonNull => format!("{}!", inner()),
            TypeKind::List => format!("[{}]", inner()),
            _ => self.name.clone().unwrap_or_default(),
        }
    }

    /// The innermost named type, ignoring list and non-null wrappers.
    pub fn named(&self) -> Option<&str> {
        match &self.of_type {
            Some(inner) => inner.named(),
            None => self.name.as_deref(),
        }
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Root {
    Query,
    Mutation,
    Subscription,
}

impl Root {
    pub const ALL: [Root; 3] = [Root::Query, Root::Mutation, Root::Subscription];

    pub fn label(self) -> &'static str {
        match self {
            Root::Query => "Query",
            Root::Mutation => "Mutation",
            Root::Subscription => "Subscription",
        }
    }
}

impl Schema {
    pub fn root_type_name(&self, root: Root) -> Option<&str> {
        let name = match root {
            Root::Query => &self.query_type,
            Root::Mutation => &self.mutation_type,
            Root::Subscription => &self.subscription_type,
        };
        name.as_ref().map(|t| t.name.as_str())
    }

    pub fn root_type(&self, root: Root) -> Option<&FullType> {
        self.type_by_name(self.root_type_name(root)?)
    }

    pub fn type_by_name(&self, name: &str) -> Option<&FullType> {
        self.types.iter().find(|t| t.name.as_deref() == Some(name))
    }

    /// Like `type_by_name`, but `Query`, `Mutation` and `Subscription` also
    /// resolve to the server's root types even when they are named differently.
    pub fn resolve_type(&self, name: &str) -> Option<&FullType> {
        if let Some(found) = self.type_by_name(name) {
            return Some(found);
        }
        let root = Root::ALL.into_iter().find(|r| r.label() == name)?;
        self.root_type(root)
    }

    pub fn is_root_type(&self, name: &str) -> bool {
        Root::ALL
            .into_iter()
            .any(|r| self.root_type_name(r) == Some(name))
    }
}
```

```rust
//! Search over a schema's operations (root fields) and named types.

use serde::Serialize;

use crate::schema::{Root, Schema};

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize)]
#[serde(rename_all = "lowercase")]
pub enum HitKind {
    Query,
    Mutation,
    Subscription,
    Type,
}

impl HitKind {
    fn rank(self) -> u8 {
        match self {
            HitKind::Query => 0,
            HitKind::Mutation => 1,
            HitKind::Subscription => 2,
            HitKind::Type => 3,
        }
    }
}

fn kind_of(root: Root) -> HitKind {
    match root {
        Root::Query => HitKind::Query,
        Root::Mutation => HitKind::Mutation,
        Root::Subscription => HitKind::Subscription,
    }
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
pub struct Hit {
    pub kind: HitKind,
    /// `Query.userRead` for operations, `User` for types. Feed it to `describe::detail`.
    pub path: String,
    /// Field signature for operations, type kind (e.g. `OBJECT`) for types.
    pub summary: String,
}

type Ranked = Vec<((bool, u8, String), Hit)>;

pub fn search(schema: &Schema, text: &str) -> Vec<Hit> {
    let needle = text.trim().to_lowercase();
    let mut ranked: Ranked = Vec::new();

    for root in Root::ALL {
        let Some(ty) = schema.root_type(root) else {
            continue;
        };
        for field in ty.fields.iter().flatten() {
            let path = format!("{}.{}", root.label(), field.name);
            push_if_match(
                &mut ranked,
                &needle,
                kind_of(root),
                &field.name,
                path,
                field.signature(),
            );
        }
    }

    for ty in &schema.types {
        let Some(name) = ty.name.as_deref() else {
            continue;
        };
        if name.starts_with("__") || schema.is_root_type(name) {
            continue;
        }
        push_if_match(
            &mut ranked,
            &needle,
            HitKind::Type,
            name,
            name.to_string(),
            ty.kind.as_str().to_string(),
        );
    }

    ranked.sort_by(|a, b| a.0.cmp(&b.0));
    ranked.into_iter().map(|(_, hit)| hit).collect()
}

fn push_if_match(
    ranked: &mut Ranked,
    needle: &str,
    kind: HitKind,
    bare_name: &str,
    path: String,
    summary: String,
) {
    let bare_lower = bare_name.to_lowercase();
    let haystack = if needle.contains('.') {
        path.to_lowercase()
    } else {
        bare_lower.clone()
    };
    if !haystack.contains(needle) {
        return;
    }
    let is_prefix = haystack.starts_with(needle);
    ranked.push((
        (!is_prefix, kind.rank(), bare_lower),
        Hit {
            kind,
            path,
            summary,
        },
    ));
}
```

```rust
//! A navigable view of one type or one field, shared by the CLI and the TUI.

use serde::Serialize;

use crate::schema::{FullType, Schema};

#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
pub struct NavItem {
    pub label: String,
    /// A path accepted by [`detail`], or `None` when the item cannot be followed.
    pub target: Option<String>,
    pub description: String,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
pub struct Detail {
    pub title: String,
    pub body: String,
    pub nav: Vec<NavItem>,
}

#[derive(Debug, thiserror::Error)]
pub enum DescribeError {
    #[error("type `{0}` not found")]
    TypeNotFound(String),
    #[error("field `{field}` not found on type `{type_name}`")]
    FieldNotFound { type_name: String, field: String },
}

/// Describe `Type` or `Type.field`.
pub fn detail(schema: &Schema, target: &str) -> Result<Detail, DescribeError> {
    let (type_part, field_part) = match target.split_once('.') {
        Some((t, f)) => (t, Some(f)),
        None => (target, None),
    };
    let ty = schema
        .resolve_type(type_part)
        .ok_or_else(|| DescribeError::TypeNotFound(type_part.to_string()))?;
    match field_part {
        None => Ok(type_detail(ty)),
        Some(field) => field_detail(type_part, ty, field),
    }
}

fn type_detail(ty: &FullType) -> Detail {
    let name = ty.name.clone().unwrap_or_default();
    let mut nav = Vec::new();

    for field in ty.fields.iter().flatten() {
        nav.push(NavItem {
            label: field.signature(),
            target: field.ty.named().map(str::to_string),
            description: field.description.clone().unwrap_or_default(),
        });
    }
    for input in ty.input_fields.iter().flatten() {
        nav.push(NavItem {
            label: input.render(),
            target: input.ty.named().map(str::to_string),
            description: input.description.clone().unwrap_or_default(),
        });
    }
    for value in ty.enum_values.iter().flatten() {
        nav.push(NavItem {
            label: value.name.clone(),
            target: None,
            description: value.description.clone().unwrap_or_default(),
        });
    }
    for possible in ty.possible_types.iter().flatten() {
        nav.push(NavItem {
            label: possible.render(),
            target: possible.named().map(str::to_string),
            description: String::new(),
        });
    }

    Detail {
        title: format!("{name} ({})", ty.kind.as_str()),
        body: ty.description.clone().unwrap_or_default(),
        nav,
    }
}

fn field_detail(type_label: &str, ty: &FullType, field_name: &str) -> Result<Detail, DescribeError> {
    let field = ty
        .fields
        .iter()
        .flatten()
        .find(|f| f.name == field_name)
        .ok_or_else(|| DescribeError::FieldNotFound {
            type_name: type_label.to_string(),
            field: field_name.to_string(),
        })?;

    let mut body = field.description.clone().unwrap_or_default();
    if field.is_deprecated {
        let reason = field.deprecation_reason.as_deref().unwrap_or("no reason given");
        if !body.is_empty() {
            body.push_str("\n\n");
        }
        body.push_str(&format!("Deprecated: {reason}"));
    }

    let mut nav = vec![NavItem {
        label: format!("returns {}", field.ty.render()),
        target: field.ty.named().map(str::to_string),
        description: String::new(),
    }];
    for arg in &field.args {
        nav.push(NavItem {
            label: arg.render(),
            target: arg.ty.named().map(str::to_string),
            description: arg.description.clone().unwrap_or_default(),
        });
    }

    Ok(Detail {
        title: format!("{type_label}.{}", field.signature()),
        body,
        nav,
    })
}

/// Plain-text rendering used by `vega --describe`.
pub fn render_text(detail: &Detail) -> String {
    let mut out = String::new();
    out.push_str(&detail.title);
    out.push('\n');
    if !detail.body.is_empty() {
        out.push('\n');
        out.push_str(&detail.body);
        out.push('\n');
    }
    if !detail.nav.is_empty() {
        out.push('\n');
    }
    for item in &detail.nav {
        out.push_str("  ");
        out.push_str(&item.label);
        out.push('\n');
        for line in item.description.lines() {
            out.push_str(format!("      {line}").trim_end());
            out.push('\n');
        }
    }
    out
}
```

```rust
//! XDG base directory resolution for vega's own subdirectories.

use std::path::PathBuf;

/// An absolute `$XDG_*` value wins; relative or empty values are ignored per the
/// XDG spec; otherwise `$HOME/<fallback>`.
fn resolve(xdg_value: Option<&str>, home: Option<&str>, fallback: &str) -> Option<PathBuf> {
    if let Some(dir) = xdg_value {
        let path = PathBuf::from(dir);
        if path.is_absolute() {
            return Some(path);
        }
    }
    Some(PathBuf::from(home?).join(fallback))
}

fn app_dir(var: &str, fallback: &str) -> Option<PathBuf> {
    let xdg_value = std::env::var(var).ok();
    let home = std::env::var("HOME").ok();
    resolve(xdg_value.as_deref(), home.as_deref(), fallback).map(|dir| dir.join("vega"))
}

    app_dir("XDG_CACHE_HOME", ".cache")
}
```

```rust
//! On-disk schema cache, one file per endpoint.

use std::{
    fs, io,
    path::{Path, PathBuf},
    time::{SystemTime, UNIX_EPOCH},
};

use serde::{Deserialize, Serialize};

use crate::schema::IntrospectionResponse;

/// A cache older than this (strictly) is stale: 24 hours.
pub const STALE_AFTER_SECS: u64 = 24 * 60 * 60;

#[derive(Debug, thiserror::Error)]
pub enum CacheError {
    #[error("cache I/O error at {path}: {source}")]
    Io {
        path: PathBuf,
        #[source]
        source: io::Error,
    },
    #[error("cache file {path} is corrupt: {source}")]
    Corrupt {
        path: PathBuf,
        #[source]
        source: serde_json::Error,
    },
    #[error("cannot serialize cache entry: {0}")]
    Serialize(#[from] serde_json::Error),
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct CacheEntry {
    pub endpoint: String,
    /// Unix seconds, stored inside the file because mtime changes on copy.
    pub fetched_at: u64,
    pub response: IntrospectionResponse,
}

impl CacheEntry {
    pub fn age_secs(&self, now: u64) -> u64 {
        now.saturating_sub(self.fetched_at)
    }
}

pub fn now_secs() -> u64 {
    SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .map(|d| d.as_secs())
        .unwrap_or(0)
}

pub fn is_stale(age_secs: u64) -> bool {
    age_secs > STALE_AFTER_SECS
}

/// Coarse human-readable age: `<1m`, `5m`, `3h`, `2d`.
pub fn format_age(age_secs: u64) -> String {
    match age_secs {
        0..=59 => "<1m".to_string(),
        60..=3_599 => format!("{}m", age_secs / 60),
        3_600..=86_399 => format!("{}h", age_secs / 3_600),
        _ => format!("{}d", age_secs / 86_400),
    }
}

/// FNV-1a, 64 bit. Hand-rolled because `DefaultHasher` is not stable across Rust versions.
fn fnv1a(text: &str) -> u64 {
    let mut hash: u64 = 0xcbf2_9ce4_8422_2325;
    for byte in text.bytes() {
        hash ^= u64::from(byte);
        hash = hash.wrapping_mul(0x0100_0000_01b3);
    }
    hash
}

/// `<dir>/<readable-endpoint>-<hash>.json`. The API key is never part of this.
pub fn cache_path(dir: &Path, endpoint: &str) -> PathBuf {
    let readable: String = endpoint
        .chars()
        .map(|c| if c.is_ascii_alphanumeric() { c } else { '_' })
        .take(48)
        .collect();
    dir.join(format!("{readable}-{:016x}.json", fnv1a(endpoint)))
}

/// `Ok(None)` when no cache file exists yet.
pub fn load(path: &Path) -> Result<Option<CacheEntry>, CacheError> {
    let text = match fs::read_to_string(path) {
        Ok(text) => text,
        Err(e) if e.kind() == io::ErrorKind::NotFound => return Ok(None),
        Err(source) => {
            return Err(CacheError::Io {
                path: path.to_path_buf(),
                source,
            })
        }
    };
    serde_json::from_str(&text)
        .map(Some)
        .map_err(|source| CacheError::Corrupt {
            path: path.to_path_buf(),
            source,
        })
}

/// Writes to a temp file and renames, so a crash never leaves a half-written cache.
pub fn store(path: &Path, entry: &CacheEntry) -> Result<(), CacheError> {
    let io_err = |source: io::Error| CacheError::Io {
        path: path.to_path_buf(),
        source,
    };
    if let Some(parent) = path.parent() {
        fs::create_dir_all(parent).map_err(io_err)?;
    }
    let json = serde_json::to_string(entry)?;
    let tmp = path.with_extension("json.tmp");
    fs::write(&tmp, json).map_err(io_err)?;
    fs::rename(&tmp, path).map_err(io_err)?;
    Ok(())
}
```

```rust
//! Connection settings: CLI flag, then environment, then `config.toml`.
//! The API key is read from the environment only and is never persisted.

use std::{
    fs, io,
    path::{Path, PathBuf},
};

use serde::Deserialize;

#[derive(Debug, Default, Deserialize)]
pub struct FileConfig {
    pub uri: Option<String>,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Settings {
    pub uri: String,
    pub api_key: Option<String>,
}

#[derive(Debug, thiserror::Error)]
pub enum ConfigError {
    #[error("no GraphQL endpoint configured: pass --uri, set GRAPHQL_URI, or add `uri` to config.toml")]
    MissingUri,
    #[error("cannot read {path}: {source}")]
    Io {
        path: PathBuf,
        #[source]
        source: io::Error,
    },
    #[error("invalid config file {path}: {source}")]
    Parse {
        path: PathBuf,
        #[source]
        source: toml::de::Error,
    },
}

fn non_empty(value: Option<String>) -> Option<String> {
    value.filter(|v| !v.is_empty())
}

pub fn resolve_settings(
    flag_uri: Option<String>,
    env_uri: Option<String>,
    env_key: Option<String>,
    file: FileConfig,
) -> Result<Settings, ConfigError> {
    let uri = non_empty(flag_uri)
        .or_else(|| non_empty(env_uri))
        .or_else(|| non_empty(file.uri))
        .ok_or(ConfigError::MissingUri)?;
    Ok(Settings {
        uri,
        api_key: non_empty(env_key),
    })
}

/// Reads `<config_dir>/config.toml`; a missing file is not an error.
pub fn load_file_config(config_dir: &Path) -> Result<FileConfig, ConfigError> {
    let path = config_dir.join("config.toml");
    let text = match fs::read_to_string(&path) {
        Ok(text) => text,
        Err(e) if e.kind() == io::ErrorKind::NotFound => return Ok(FileConfig::default()),
        Err(source) => return Err(ConfigError::Io { path, source }),
    };
    toml::from_str(&text).map_err(|source| ConfigError::Parse { path, source })
}
```

```rust
//! Fetches the schema through a standard GraphQL introspection query.

use std::time::Duration;

use serde_json::{json, Value};

use crate::schema::IntrospectionResponse;

/// Standard introspection query. It leaves out `interfaces`, `isRepeatable` and
/// directives, which phase 1 does not use and which older servers may reject.
pub const INTROSPECTION_QUERY: &str = r#"
query IntrospectionQuery {
  __schema {
    queryType { name }
    mutationType { name }
    subscriptionType { name }
    types { ...FullType }
  }
}
fragment FullType on __Type {
  kind name description
  fields(includeDeprecated: true) {
    name description
    args { ...InputValue }
    type { ...TypeRef }
    isDeprecated deprecationReason
  }
  inputFields { ...InputValue }
  enumValues(includeDeprecated: true) { name description isDeprecated deprecationReason }
  possibleTypes { ...TypeRef }
}
fragment InputValue on __InputValue {
  name description
  type { ...TypeRef }
  defaultValue
}
fragment TypeRef on __Type {
  kind name
  ofType { kind name ofType { kind name ofType { kind name ofType { kind name ofType { kind name ofType { kind name ofType { kind name } } } } } } }
}
"#;

#[derive(Debug, thiserror::Error)]
pub enum ClientError {
    #[error("request failed: {0}")]
    Http(#[from] reqwest::Error),
    #[error("server answered HTTP {status}: {body}")]
    Status { status: u16, body: String },
    #[error("response is not a valid introspection result: {0}")]
    InvalidJson(serde_json::Error),
    #[error("server returned GraphQL errors: {0}")]
    Graphql(String),
    #[error("response has no `data`")]
    MissingData,
}

pub fn request_body() -> Value {
    json!({ "query": INTROSPECTION_QUERY, "operationName": "IntrospectionQuery" })
}

pub fn parse_response(body: &str) -> Result<IntrospectionResponse, ClientError> {
    let value: Value = serde_json::from_str(body).map_err(ClientError::InvalidJson)?;
    let has_data = matches!(value.get("data"), Some(data) if !data.is_null());
    if !has_data {
        let messages = value
            .get("errors")
            .and_then(Value::as_array)
            .map(|errors| {
                errors
                    .iter()
                    .filter_map(|e| e.get("message").and_then(Value::as_str))
                    .collect::<Vec<_>>()
                    .join("; ")
            })
            .filter(|joined| !joined.is_empty());
        return Err(match messages {
            Some(messages) => ClientError::Graphql(messages),
            None => ClientError::MissingData,
        });
    }
    serde_json::from_value(value).map_err(ClientError::InvalidJson)
}

pub fn fetch_introspection(
    uri: &str,
    api_key: Option<&str>,
) -> Result<IntrospectionResponse, ClientError> {
    let client = reqwest::blocking::Client::builder()
        .timeout(Duration::from_secs(60))
        .build()?;
    let mut request = client.post(uri).json(&request_body());
    if let Some(key) = api_key {
        request = request.header("X-API-Key", key);
    }
    let response = request.send()?;
    let status = response.status();
    let body = response.text()?;
    if !status.is_success() {
        return Err(ClientError::Status {
            status: status.as_u16(),
            body: body.chars().take(300).collect(),
        });
    }
    parse_response(&body)
}
```

```rust
//! Where the schema comes from: the cache, or a fresh introspection fetch.

use std::path::Path;

use anyhow::Context;
use vega_core::cache::{self, CacheEntry};
use vega_core::client;
use vega_core::config::Settings;

/// Use the cache unless `refresh` is set or no usable cache exists. A failed fetch
/// returns an error and leaves any existing cache file untouched.
pub fn load_or_fetch(
    settings: &Settings,
    cache_file: &Path,
    refresh: bool,
) -> anyhow::Result<CacheEntry> {
    if !refresh {
        match cache::load(cache_file) {
            Ok(Some(entry)) => return Ok(entry),
            Ok(None) => {}
            Err(e) => eprintln!("warning: ignoring unusable cache ({e}); fetching a fresh schema"),
        }
    }
    let entry = fetch_entry(settings)?;
    cache::store(cache_file, &entry).context("could not write the schema cache")?;
    Ok(entry)
}

pub fn fetch_entry(settings: &Settings) -> anyhow::Result<CacheEntry> {
    let response = client::fetch_introspection(&settings.uri, settings.api_key.as_deref())
        .with_context(|| format!("fetching the schema from {}", settings.uri))?;
    Ok(CacheEntry {
        endpoint: settings.uri.clone(),
        fetched_at: cache::now_secs(),
        response,
    })
}
```

```rust
    std::env::var(name).ok()

fn main() -> anyhow::Result<()> {
    let cli = Cli::parse();

    let file_config = match xdg::config_dir() {
        Some(dir) => config::load_file_config(&dir)?,
        None => FileConfig::default(),
    };
    let settings = config::resolve_settings(
        cli.uri.clone(),
        env_var("GRAPHQL_URI"),
        env_var("GRAPHQL_KEY"),
        file_config,
    )?;

    let cache_dir = xdg::cache_dir()
        .context("cannot locate the cache directory: set XDG_CACHE_HOME or HOME")?;
    let cache_file = cache::cache_path(&cache_dir, &settings.uri);
    let entry = schema_source::load_or_fetch(&settings, &cache_file, cli.refresh)?;
    let age = entry.age_secs(cache::now_secs());
    let schema = &entry.response.data.schema;

    if cli.search.is_some() || cli.describe.is_some() {
        if cache::is_stale(age) {
            eprintln!(
                "warning: the schema cache for {} was fetched {} ago; run with --refresh to update it",
                settings.uri,
                cache::format_age(age)
            );
        }
        if let Some(text) = &cli.search {
            let hits = search::search(schema, text);
            if cli.json {
                println!("{}", serde_json::to_string_pretty(&hits)?);
            } else {
                print!("{}", output::hits_text(&hits));
            }
        } else if let Some(target) = &cli.describe {
            let detail = describe::detail(schema, target)?;
            if cli.json {
                println!("{}", serde_json::to_string_pretty(&detail)?);
            } else {
                print!("{}", describe::render_text(&detail));
            }
        }
        return Ok(());
    }

    anyhow::bail!("the interactive browser is not wired up yet; use --search or --describe")
}
```

```rust
    back_stack: Vec<DetailView>,
    pub refresh: RefreshState,
    pub should_quit: bool,
}

/// `https://nexus.example.com/graphql` becomes `nexus.example.com`.
fn host_of(uri: &str) -> String {
    let rest = uri.split_once("://").map_or(uri, |(_, rest)| rest);
    rest.split('/').next().unwrap_or(rest).to_string()
}

impl App {
    pub fn new(schema: Schema, uri: &str, fetched_at: u64) -> Self {
        let hits = search::search(&schema, "");
        Self {
            schema,
            host: host_of(uri),
            fetched_at,
            query: String::new(),
            hits,
            hit_index: 0,
            detail: None,
            back_stack: Vec::new(),
            refresh: RefreshState::Idle,
            should_quit: false,
        }
    }

    pub fn handle_key(&mut self, key: KeyEvent) -> Action {
        if key.modifiers.contains(KeyModifiers::CONTROL) {
            return match key.code {
                KeyCode::Char('c') => {
                    self.should_quit = true;
                    Action::None
                }
                KeyCode::Char('r') => self.request_refresh(),
                _ => Action::None,
            };
        }
        if self.detail.is_some() {
            self.handle_detail_key(key.code);
        } else {
            self.handle_search_key(key.code);
        }
        Action::None
    }

    fn request_refresh(&mut self) -> Action {
        if self.refresh == RefreshState::Running {
            return Action::None;
        }
        self.refresh = RefreshState::Running;
        Action::Refresh
    }

    fn handle_search_key(&mut self, code: KeyCode) {
        match code {
            KeyCode::Esc => self.should_quit = true,
            KeyCode::Char(c) => {
                self.query.push(c);
                self.rerun_search();
            }
            KeyCode::Backspace => {
                self.query.pop();
                self.rerun_search();
            }
            KeyCode::Down => {
                self.hit_index = (self.hit_index + 1).min(self.hits.len().saturating_sub(1));
            }
            KeyCode::Up => self.hit_index = self.hit_index.saturating_sub(1),
            KeyCode::Enter => self.open_highlighted_hit(),
            _ => {}
        }
    }

    fn handle_detail_key(&mut self, code: KeyCode) {
        let Some(view) = self.detail.as_mut() else {
            return;
        };
        match code {
            KeyCode::Char('q') => self.should_quit = true,
            KeyCode::Esc | KeyCode::Backspace => self.go_back(),
            KeyCode::Down => {
                view.selected = (view.selected + 1).min(view.detail.nav.len().saturating_sub(1));
            }
            KeyCode::Up => view.selected = view.selected.saturating_sub(1),
            KeyCode::Enter => self.follow_selected(),
            _ => {}
        }
    }

    fn rerun_search(&mut self) {
        self.hits = search::search(&self.schema, &self.query);
        self.hit_index = 0;
    }

    fn open_highlighted_hit(&mut self) {
        let Some(hit) = self.hits.get(self.hit_index) else {
            return;
        };
        if let Ok(detail) = describe::detail(&self.schema, &hit.path) {
            self.detail = Some(DetailView {
                detail,
                selected: 0,
            });
        }
    }

    fn follow_selected(&mut self) {
        let Some(view) = &self.detail else {
            return;
        };
        let Some(target) = view
            .detail
            .nav
            .get(view.selected)
            .and_then(|item| item.target.clone())
        else {
            return;
        };
        let Ok(next) = describe::detail(&self.schema, &target) else {
            return;
        };
        let next = DetailView {
            detail: next,
            selected: 0,
        };
        if let Some(current) = self.detail.replace(next) {
            self.back_stack.push(current);
        }
    }

    /// Pops the history; with nothing left, returns to the search list.
    fn go_back(&mut self) {
        self.detail = self.back_stack.pop();
    }

    /// Detail of the highlighted search hit, shown while no detail is open.
    pub fn preview(&self) -> Option<Detail> {
        let hit = self.hits.get(self.hit_index)?;
        describe::detail(&self.schema, &hit.path).ok()
    }

    pub fn apply_refresh_ok(&mut self, schema: Schema, fetched_at: u64) {
        self.schema = schema;
        self.fetched_at = fetched_at;
        self.detail = None;
        self.back_stack.clear();
        self.refresh = RefreshState::Idle;
        self.rerun_search();
    }

    pub fn apply_refresh_err(&mut self, message: String) {
        self.refresh = RefreshState::Failed(message);
    }

    /// Status bar text and its staleness level at time `now` (unix seconds).
    pub fn status(&self, now: u64) -> (String, StatusLevel) {
        let age = now.saturating_sub(self.fetched_at);
        let level = if is_stale(age) {
            StatusLevel::Stale
        } else {
            StatusLevel::Fresh
        };
        let mut text = format!("{} · schema fetched {} ago", self.host, format_age(age));
        match &self.refresh {
            RefreshState::Idle => text.push_str(" · Ctrl-R refresh"),
            RefreshState::Running => text.push_str(" · refreshing…"),
            RefreshState::Failed(message) => {
                let first_line = message.lines().next().unwrap_or("");
                text.push_str(&format!(" · refresh failed: {first_line} · Ctrl-R retry"));
            }
        }
        (text, level)
    }
}
```

```rust
//! Terminal setup and the event loop. Everything testable lives in `app` and `ui`.

pub mod app;
pub mod ui;

use std::{
    path::{Path, PathBuf},
    sync::mpsc,
    thread,
    time::Duration,
};

use ratatui::{
    crossterm::event::{self, Event, KeyEventKind},
    DefaultTerminal,
};
use vega_core::cache::{self, CacheEntry};
use vega_core::config::Settings;

use crate::schema_source;
use app::{Action, App};

pub fn run(entry: CacheEntry, settings: Settings, cache_file: PathBuf) -> anyhow::Result<()> {
    let app = App::new(entry.response.data.schema, &settings.uri, entry.fetched_at);
    let mut terminal = ratatui::init();
    let result = event_loop(&mut terminal, app, &settings, &cache_file);
    ratatui::restore();
    result
}

fn event_loop(
    terminal: &mut DefaultTerminal,
    mut app: App,
    settings: &Settings,
    cache_file: &Path,
) -> anyhow::Result<()> {
    let (tx, rx) = mpsc::channel::<anyhow::Result<CacheEntry>>();

    while !app.should_quit {
        terminal.draw(|frame| ui::draw(frame, &app, cache::now_secs()))?;

        while let Ok(result) = rx.try_recv() {
            match persist(cache_file, result) {
                Ok(entry) => app.apply_refresh_ok(entry.response.data.schema, entry.fetched_at),
                Err(e) => app.apply_refresh_err(format!("{e:#}")),
            }
        }

        // Short poll so the status bar age keeps ticking and refresh results show up.
        if event::poll(Duration::from_millis(200))? {
            if let Event::Key(key) = event::read()? {
                if key.kind == KeyEventKind::Press && app.handle_key(key) == Action::Refresh {
                    let settings = settings.clone();
                    let tx = tx.clone();
                    thread::spawn(move || {
                        let _ = tx.send(schema_source::fetch_entry(&settings));
                    });
                }
            }
        }
    }
    Ok(())
}

/// Writes a freshly fetched schema to the cache. A failed fetch leaves the cache alone.
fn persist(cache_file: &Path, result: anyhow::Result<CacheEntry>) -> anyhow::Result<CacheEntry> {
    let entry = result?;
    cache::store(cache_file, &entry)?;
    Ok(entry)
}
```
