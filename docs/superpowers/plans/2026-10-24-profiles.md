# Saved Server Profiles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Save servers (endpoint plus credentials) as named profiles, with the credentials in the OS keyring, and switch between them from the TUI (`Ctrl-P`) or the CLI (`--profile`, `VEGA_PROFILE`).

**Architecture:** `vega-core` gets a `profile` module (the `config.toml` part and the secret mapping), a `secrets` module (a `SecretStore` trait with a keyring implementation and an in-memory test fake) and the save/delete/connect operations on top of them. The TUI stays a set of pure state machines: the connection modal gains a "Save as" field and `Ctrl-S`, a new `Picker` lists profiles, and `App` returns new `Action`s that the event loop in `tui/mod.rs` performs (keyring and file IO happen only there).

**Tech Stack:** Rust 2021, `keyring` 4.x (default `v1` feature), `toml_edit` (comment-preserving writes of `config.toml`), existing `toml`/`serde`/`thiserror`/`ratatui`/`clap`.

Spec: `docs/superpowers/specs/2026-10-24-profiles-design.md`. Read `AGENTS.md` first: commits are atomic, `tag: subject` (≤ 72 chars, tags `feat fix ref doc test chore`), no AI attribution, every commit must pass `just check` (clippy runs with `-D warnings`, so an unused item in the binary crate fails a commit: wire things in the same commit that adds them). Run `just hooks` once so `commit-msg` enforces this.

Decisions taken while planning, which refine the spec (Task 8 updates the spec to match):

- Profile `kind` has three values: `none`, `api_key`, `headers`.
- On a failed config write, the keyring is restored to its previous value (or the entry is deleted if there was none), instead of always deleting it, so a failed overwrite does not lose the old secret.
- The CLI test of `--profile` covers the unknown-profile error through the binary. Everything that needs a keyring is covered in `vega-core` with the in-memory fake, because the binary always uses the real keyring.
- If the environment supplies credentials (`VEGA_GRAPHQL_KEY` or `VEGA_GRAPHQL_HEADERS`), they replace the profile's credentials entirely (no merge).

```rust
//! Saved server profiles. The non-secret part (endpoint, kind of credentials, API key
//! header name) lives in `config.toml`; the secret lives in the OS keyring.

use serde::{Deserialize, Serialize};

use crate::{
    config::Settings,
    headers::{self, Header, DEFAULT_KEY_HEADER},
};

/// How a profile authenticates; it decides what its keyring secret holds.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub enum Kind {
    /// No credentials, no keyring entry.
    #[serde(rename = "none")]
    NoAuth,
    /// The secret is the API key value.
    #[serde(rename = "api_key")]
    ApiKey,
    /// The secret is `Name: value` lines (the `VEGA_GRAPHQL_HEADERS` format).
    #[serde(rename = "headers")]
    Headers,
}

impl Kind {
    pub fn as_str(self) -> &'static str {
        match self {
            Kind::NoAuth => "none",
            Kind::ApiKey => "api_key",
            Kind::Headers => "headers",
        }
    }
}

/// The part of a profile that is safe to write to `config.toml`.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Profile {
    pub uri: String,
    pub kind: Kind,
    /// Header name of an `api_key` profile (a name is not a secret).
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub key_header: Option<String>,
}

#[derive(Debug, thiserror::Error)]
pub enum ProfileError {
    #[error("a profile name may only contain letters, digits, '-' and '_'")]
    InvalidName,
    #[error("no profile named `{name}` (saved: {known})")]
    Unknown { name: String, known: String },
    #[error("the stored credentials are not valid: save the profile again")]
    BadCredentials,
    #[error(transparent)]
    Secret(#[from] crate::secrets::SecretError),
    #[error(transparent)]
    Config(#[from] crate::config::ConfigError),
    #[error(
        "could not save profile `{name}` and could not restore its keyring entry `vega/{name}`: {source}"
    )]
    Orphan {
        name: String,
        source: crate::config::ConfigError,
    },
}

/// Names are used as a TOML key and as the keyring user, so they stay plain.
pub fn validate_name(name: &str) -> Result<(), ProfileError> {
    let plain = !name.is_empty()
        && name
            .chars()
            .all(|c| c.is_ascii_alphanumeric() || c == '-' || c == '_');
    if plain {
        Ok(())
    } else {
        Err(ProfileError::InvalidName)
    }
}

impl Profile {
    /// Splits settings into the part for `config.toml` and the secret for the keyring.
    pub fn from_settings(settings: &Settings) -> (Profile, Option<String>) {
        let uri = settings.uri.clone();
        match settings.headers.as_slice() {
            [] => (
                Profile {
                    uri,
                    kind: Kind::NoAuth,
                    key_header: None,
                },
                None,
            ),
            [key] if settings.key_only => (
                Profile {
                    uri,
                    kind: Kind::ApiKey,
                    key_header: Some(key.name().to_string()),
                },
                Some(key.value().to_string()),
            ),
            all => (
                Profile {
                    uri,
                    kind: Kind::Headers,
                    key_header: None,
                },
                Some(headers::to_lines(all)),
            ),
        }
    }

    /// Rebuilds the settings from the keyring secret. Without a secret there are no
    /// headers.
    pub fn settings(&self, secret: Option<&str>) -> Result<Settings, ProfileError> {
        let mut settings = Settings {
            uri: self.uri.clone(),
            headers: Vec::new(),
            key_only: false,
        };
        let Some(secret) = secret else {
            return Ok(settings);
        };
        match self.kind {
            Kind::NoAuth => {}
            Kind::ApiKey => {
                let name = self.key_header.as_deref().unwrap_or(DEFAULT_KEY_HEADER);
                let header =
                    Header::new(name, secret).map_err(|_| ProfileError::BadCredentials)?;
                settings.headers = vec![header];
                settings.key_only = true;
            }
            Kind::Headers => {
                settings.headers =
                    headers::parse_lines(secret).map_err(|_| ProfileError::BadCredentials)?;
            }
        }
        Ok(settings)
    }
}
```

```rust
/// Every Vega secret lives under this keyring service; the user is the profile name.
pub const SERVICE: &str = "vega";

pub trait SecretStore {
    /// `None` when there is no entry for `name`.
    fn get(&self, name: &str) -> Result<Option<String>, SecretError>;
    fn set(&self, name: &str, secret: &str) -> Result<(), SecretError>;
    /// A missing entry is not an error.
    fn delete(&self, name: &str) -> Result<(), SecretError>;
}

/// The operating system keyring (Secret Service, Keychain or Credential Manager).
pub struct KeyringStore;

fn map_error(error: keyring::Error) -> SecretError {
    match error {
        keyring::Error::NoDefaultStore => SecretError::Unavailable,
        keyring::Error::NoStorageAccess(_) => SecretError::Denied,
        // `keyring` errors describe the failure, never the secret.
        other => SecretError::Backend(other.to_string()),
    }
}

impl KeyringStore {
    fn entry(name: &str) -> Result<keyring::Entry, SecretError> {
        keyring::Entry::new(SERVICE, name).map_err(map_error)
    }
}

impl SecretStore for KeyringStore {
    fn get(&self, name: &str) -> Result<Option<String>, SecretError> {
        match Self::entry(name)?.get_password() {
            Ok(secret) => Ok(Some(secret)),
            Err(keyring::Error::NoEntry) => Ok(None),
            Err(error) => Err(map_error(error)),
        }
    }

    fn set(&self, name: &str, secret: &str) -> Result<(), SecretError> {
        Self::entry(name)?.set_password(secret).map_err(map_error)
    }

    fn delete(&self, name: &str) -> Result<(), SecretError> {
        match Self::entry(name)?.delete_credential() {
            Ok(()) | Err(keyring::Error::NoEntry) => Ok(()),
            Err(error) => Err(map_error(error)),
        }
    }
}

/// An in-memory store for tests, with switches to make writes fail.
#[cfg(test)]
#[derive(Default)]
pub struct MemoryStore {
    secrets: std::sync::Mutex<std::collections::HashMap<String, String>>,
    fail_sets: bool,
    fail_deletes: bool,
}

#[cfg(test)]
impl MemoryStore {
    pub fn failing_sets() -> Self {
        Self {
            fail_sets: true,
            ..Self::default()
        }
    }

    pub fn failing_deletes() -> Self {
        Self {
            fail_deletes: true,
            ..Self::default()
        }
    }

    fn map(
        &self,
    ) -> std::sync::MutexGuard<'_, std::collections::HashMap<String, String>> {
        self.secrets.lock().unwrap_or_else(|p| p.into_inner())
    }
}

#[cfg(test)]
impl SecretStore for MemoryStore {
    fn get(&self, name: &str) -> Result<Option<String>, SecretError> {
        Ok(self.map().get(name).cloned())
    }

    fn set(&self, name: &str, secret: &str) -> Result<(), SecretError> {
        if self.fail_sets {
            return Err(SecretError::Backend("injected".to_string()));
        }
        self.map().insert(name.to_string(), secret.to_string());
        Ok(())
    }

    fn delete(&self, name: &str) -> Result<(), SecretError> {
        if self.fail_deletes {
            return Err(SecretError::Backend("injected".to_string()));
        }
        self.map().remove(name);
        Ok(())
    }
}
```

```rust
/// A profile ready to use.
#[derive(Debug)]
pub struct Connected {
    pub settings: Settings,
    /// The profile needs credentials but the keyring has none for it.
    pub missing_credentials: bool,
}

/// Looks the profile up and reads its secret from `store`.
pub fn connect(
    file: &FileConfig,
    store: &dyn SecretStore,
    name: &str,
) -> Result<Connected, ProfileError> {
    let Some(profile) = file.profiles.get(name) else {
        let known = if file.profiles.is_empty() {
            "none".to_string()
        } else {
            file.profiles.keys().cloned().collect::<Vec<_>>().join(", ")
        };
        return Err(ProfileError::Unknown {
            name: name.to_string(),
            known,
        });
    };
    let secret = match profile.kind {
        Kind::NoAuth => None,
        _ => store.get(name)?,
    };
    let missing_credentials = profile.kind != Kind::NoAuth && secret.is_none();
    Ok(Connected {
        settings: profile.settings(secret.as_deref())?,
        missing_credentials,
    })
}

/// Saves `settings` as profile `name`: the secret to `store` first, then the rest to
/// `<dir>/config.toml`. If the config write fails the keyring is put back as it was.
pub fn save(
    dir: &Path,
    store: &dyn SecretStore,
    name: &str,
    settings: &Settings,
) -> Result<(), ProfileError> {
    validate_name(name)?;
    let (profile, secret) = Profile::from_settings(settings);
    let previous = store.get(name)?;
    match &secret {
        Some(secret) => store.set(name, secret)?,
        None => store.delete(name)?,
    }
    let written = edit_config(dir, |profiles| {
        let mut table = Table::new();
        table["uri"] = value(profile.uri.as_str());
        table["kind"] = value(profile.kind.as_str());
        if let Some(header) = &profile.key_header {
            table["key_header"] = value(header.as_str());
        }
        profiles.insert(name, Item::Table(table));
    });
    if let Err(error) = written {
        let restored = match previous {
            Some(previous) => store.set(name, &previous),
            None => store.delete(name),
        };
        return Err(match restored {
            Ok(()) => error.into(),
            Err(_) => ProfileError::Orphan {
                name: name.to_string(),
                source: error,
            },
        });
    }
    Ok(())
}

/// Removes the secret, then the config entry. A profile that is not there is fine.
pub fn delete(dir: &Path, store: &dyn SecretStore, name: &str) -> Result<(), ProfileError> {
    store.delete(name)?;
    edit_config(dir, |profiles| {
        profiles.remove(name);
    })?;
    Ok(())
}

/// Applies `change` to the `[profiles]` table and writes the file back through a
/// temporary file, keeping comments and unrelated entries.
fn edit_config(dir: &Path, change: impl FnOnce(&mut Table)) -> Result<(), ConfigError> {
    let path = dir.join("config.toml");
    let io_error = |source: io::Error| ConfigError::Io {
        path: path.clone(),
        source,
    };
    let text = match fs::read_to_string(&path) {
        Ok(text) => text,
        Err(e) if e.kind() == io::ErrorKind::NotFound => String::new(),
        Err(e) => return Err(io_error(e)),
    };
    let mut document: DocumentMut = text
        .parse()
        .map_err(|e: toml_edit::TomlError| io_error(io::Error::new(io::ErrorKind::InvalidData, e.to_string())))?;
    let profiles = document
        .entry("profiles")
        .or_insert(Item::Table(Table::new()))
        .as_table_mut()
        .ok_or_else(|| {
            io_error(io::Error::new(
                io::ErrorKind::InvalidData,
                "`profiles` is not a table",
            ))
        })?;
    // Print `[profiles.name]` without an empty `[profiles]` header above it.
    profiles.set_implicit(true);
    change(profiles);
    fs::create_dir_all(dir).map_err(&io_error)?;
    let temporary = dir.join("config.toml.tmp");
    fs::write(&temporary, document.to_string()).map_err(&io_error)?;
    fs::rename(&temporary, &path).map_err(&io_error)?;
    Ok(())
}
```

```rust
//! The profile picker: a pure state machine (key in, outcome out), like the connection
//! modal. It never holds or shows a header value.

use ratatui::crossterm::event::{KeyCode, KeyEvent};
use vega_core::profile::Kind;

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Entry {
    pub name: String,
    pub uri: String,
    pub kind: Kind,
}

/// What a key did to the picker.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Outcome {
    Open,
    Close,
    Connect(String),
    Edit(String),
    New,
    Delete(String),
}

pub struct Picker {
    entries: Vec<Entry>,
    selected: usize,
    current: Option<String>,
    confirming: bool,
}

impl Picker {
    pub fn new(entries: Vec<Entry>, current: Option<String>) -> Self {
        let selected = current
            .as_deref()
            .and_then(|name| entries.iter().position(|entry| entry.name == name))
            .unwrap_or(0);
        Self {
            entries,
            selected,
            current,
            confirming: false,
        }
    }

    pub fn entries(&self) -> &[Entry] {
        &self.entries
    }

    pub fn selected(&self) -> usize {
        self.selected
    }

    /// The profile in use, which the list marks.
    pub fn current(&self) -> Option<&str> {
        self.current.as_deref()
    }

    /// True while the delete question is showing.
    pub fn confirming(&self) -> bool {
        self.confirming
    }

    pub fn handle_key(&mut self, key: KeyEvent) -> Outcome {
        let name = self.entries.get(self.selected).map(|e| e.name.clone());
        if self.confirming {
            self.confirming = false;
            return match (key.code, name) {
                (KeyCode::Char('y' | 'Y'), Some(name)) => Outcome::Delete(name),
                _ => Outcome::Open,
            };
        }
        match key.code {
            KeyCode::Esc => Outcome::Close,
            KeyCode::Up => {
                self.selected = self.selected.saturating_sub(1);
                Outcome::Open
            }
            KeyCode::Down => {
                self.selected = (self.selected + 1).min(self.entries.len().saturating_sub(1));
                Outcome::Open
            }
            KeyCode::Enter => name.map_or(Outcome::Open, Outcome::Connect),
            KeyCode::Char('e') => name.map_or(Outcome::Open, Outcome::Edit),
            KeyCode::Char('n') => Outcome::New,
            KeyCode::Char('d') => {
                self.confirming = name.is_some();
                Outcome::Open
            }
            _ => Outcome::Open,
        }
    }
}
```

```rust
fn read_profiles(config_dir: Option<&Path>) -> Result<vega_core::config::FileConfig, String> {
```

```rust
    let width = area.width.min(76);
    let height = area.height.min(16);
    let popup = Rect::new(
        area.x + (area.width - width) / 2,
```
